# gaussian_beam

TEM00 beam radius, wavefront curvature, Gouy phase, Rayleigh range, the complex beam parameter q and the ABCD law. SI units; wavelength is the vacuum wavelength.

Version 1. Functions: `beam_parameters`, `beam_at`, `thin_lens_focus` (Result); helpers `q_parameter`, `free_space`, `thin_lens`, `abcd_propagate`, `beam_from_q`.
