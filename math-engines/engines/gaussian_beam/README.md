# gaussian_beam

TEM00 beam propagation (Rayleigh range, w(z), R(z), Gouy phase) with M² and refractive-index
scaling, the complex beam parameter q = (z − z0) + i z_R and the ABCD law. This is also the
template engine: copy this folder to start a new one.

Conventions: SI units, vacuum wavelength, `distance_to_waist > 0` means the waist lies downstream.

Version history: 1 — first release.
