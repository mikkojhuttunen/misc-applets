# materials

Sellmeier phase and group index for SiO₂, Si₃N₄, LiNbO₃ (5 % MgO, e and o), LiTaO₃ (extraordinary and ordinary, approximate fits, ±0.01), Si (real part) and amorphous Al₂O₃ / Er:Al₂O₃ (Cauchy fit to sputtered films). Input: vacuum wavelength in m.

Version 2 (added lt_o, al2o3, er_al2o3). `refractive_index` returns a Result; `index` is a plain-array helper for other engines.
