# parametric_amplifier

Fiber optical parametric amplification:

* `coupling` — gain coefficient Γ from d_eff (chi2) or n2 (chi3) and Gaussian mode sizes.
* `small_signal_gain` — exact undepleted-pump gain with continuous or lumped idler loss and
  optional signal loss from a real filter (2×2 matrix exponential), vectorised over the mismatch.
* `amplify` — RK4 coupled-wave solution with pump depletion, SPM/XPM (chi3), idler/signal/pump
  loss, idler dumps and optional SBS/SRS (uses `stimulated_scattering`).
* `gain_bandwidth` — signal and idler −3 dB width in rad/s, Hz and nm for a Taylor phase mismatch.

Conventions: SI units; losses are power coefficients in 1/m and dump transmissions are power
ratios (convert dB at the edge). For chi3, `phase_mismatch` is the net κ = Δβ + 2γP. Gain is
symmetric in the sign of the mismatch.

The browser applet `amplifiers/parametric-amplifiers/` uses a JavaScript port of these
functions (`opa_engine.js`) because its spectra and optimiser need tens of thousands of solver
runs per second. `test_vectors.json` (generated by `tools/make_test_vectors.py`) keeps the port in
step with this reference implementation.
