# slab_waveguide

Three-layer slab modes from the transcendental dispersion relation (TE/TM, any order) and a transfer-matrix solver for arbitrary stacks (`multilayer_neff`, e.g. SiO₂ | TFLT | SiNx | air). SI units.

Version 1. `slab_neff` and `multilayer_neff` return Results; `neff_three_layer` is a scalar helper.
