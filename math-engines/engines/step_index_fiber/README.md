# step_index_fiber

LP01 mode of a weakly guiding silica step-index fibre: effective index from the exact LP eigenvalue equation (SciPy Bessel functions), V, b and the Marcuse mode-field radius. `phase_mismatch` gives the linear χ2 (ω_p = ω_s + ω_i) or degenerate χ3 (2ω_p = ω_s + ω_i) mismatch of the LP01 modes, its change with signal detuning, the signal–idler group-velocity mismatch, β2,s + β2,i and the χ2 QPM period. SI units.

Version 2 (adds `phase_mismatch`; `lp01` unchanged). Requires SciPy.
