# stimulated_scattering

Brillouin (shift, linewidth, linewidth-reduced gain, thermal seed, exact two-wave CW reflection,
Smith threshold) and Raman (Blow–Wood single-oscillator gain spectrum with roll-off above 32 THz,
Smith threshold, first Stokes wavelength) scattering in fused-silica fiber.

Conventions: SI units; `mode_area` is the effective area in m²; `pump_linewidth` in Hz;
Raman `frequency_shift` > 0 means the wave is on the Stokes (lower-frequency) side of the pump.

Version history: 1 — first release.
